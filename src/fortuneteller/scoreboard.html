Beat the fortune teller

How to play: on GitHub, add a file data/guesses/<day>-<handle>.csv, with the header flow,instrument,direction and one row per market (cpi,SPY / ES,up), and open a pull request that adds only that file. A guess counts only if the owner merges the pull request before 08:30 New York on its day; one merged later is void, and one never merged is not shown. The rules.

Not a fair fight: a person guesses before the release; the machine calls after it, knowing the actual, and only on the links and days it chooses.

Public and permanent: a guess stays in the repository's history and on this page. Handles are not checked, so one person can play under two; every handle's full record is shown, losses included. A handle is dropped from the page on request; the history stays.
